CESNET Invenio Sandbox

The CESNET Invenio Sandbox is an instance of the CESNET Invenio repository system. The sandbox is maintained by the NRP Invenio Repository System Specialists.

CESNET Invenio itself is an extension of InvenioRDM, a turn-key research data management (RDM) repository platform based on Invenio Framework and Zenodo. It is one of the core repository systems of the Czech National Repository Platform (NRP). To learn more about the conditions for building a new instance of the CESNET Invenio system in the NRP, see Repositories in NRP.

Aim of the sandbox

The sandbox is a safe environment where anyone can explore the standard features of CESNET Invenio. Use it to:

  • Walk through the data deposition process and enter metadata using the CESNET Invenio implementation of the Czech Core Metadata Model (CCMM)
  • Explore the API and test deposition scripts and data pipelines
  • Teach and learn about data repositories in courses and workshops

Basic usage rules

  • Anyone with a valid e-INFRA.cz identity can log in and is automatically granted permission to deposit data as an individual submitter.
  • The repository has a few demo communities where users can try out standard deposition workflows.
  • The repository assigns only test DOIs, which are not resolvable.
  • All deposited data and metadata are deleted periodically.
  • User quota are set to the following limits:
    • Max file count per record: 20
    • Max file size per user: 10 GB
    • Max file size per upload: 100 MB

Technical note

The CESNET Invenio Sandbox codebase is a fork of the Catch-all repository codebase and shares the same architecture and features. The main differences are the automatic permission to deposit data and to create communities. Otherwise, the user documentation of the Catch-all data repository (see below) applies here as well.
