CESNET Invenio Sandbox

The CESNET Invenio Sandbox is a fork of the Catch-all Data Repository maintained by the NRP Invenio Repository System Specialists.

CESNET Invenio itself is an extention of InvenioRDM, a turn-key research data management (RDM) repository platform based on Invenio Framework and Zenodo. CESNET Invenio is one of the core repository systems of the Czech National Repository Platform (NRP). To learn more about the conditions for buildng a new instance of the CESNET Invenio system in NRP, see Repositories in NRP.

Aim of the sandbox

  • Let anyone try standard features of CESNET Invenio in a safe environment
  • Trying out the data deposition process and metadata description in the Invenio implementation of the Czech Core Metadata Model (CCMM)
  • Trying out the API and testing deposition scripts and data pipelines
  • Learning about data repositories in courses and workshops

How does it differ from the Catch-all Data Repository?

  • Anyone can register via e-INFRA and their registration is automatically approved with the ability to deposit data (in the Catch-all repository users need to request permission to deposit data and wait for aproval)
  • Any user can create a community (In the Catch-all repository only the repository administrator can create new communities)
  • The repository has two demo communities where users can try out standard deposition workflows
  • The repository assigns only test DOIs which are not resolvable
  • Data is periodically wiped
